## 📌 About The Project

**ATHAR (أثَر)** is an AI-powered national decision-support system designed to predict the cascading impacts of tourism activity across key sectors in Saudi Arabia.

The system connects tourism, transportation, aviation, accommodation, energy, water, and municipal services within a unified analytical model to simulate scenarios, identify potential pressure points, and support proactive decision-making.

---

## ✨ Key Features

* **📊 Cross-Sector Analysis:** Connects tourism indicators with key national sectors.
* **🔮 Scenario Simulation:** Simulates potential tourism scenarios and their impacts.
* **⚠️ Pressure Point Detection:** Identifies where and when pressure may occur.
* **🤖 AI-Powered Insights:** Supports decision-makers with proactive recommendations.
* **🇸🇦 National-Level Planning:** Enables proactive management of tourism events and resources.

---

## 🔗 Connected Sectors

**Tourism • Transportation • Aviation • Accommodation • Energy • Water • Municipal Services**

---

## 💡 Example

**Major Tourism Event → Increased Visitors → Higher Transportation & Hotel Demand → Increased Energy, Water & Municipal Pressure**

ATHAR analyzes these cascading effects to determine **where pressure may occur, when it may happen, and what intervention can be taken beforehand.**

## 🚀 How to Run Locally

### 1. Clone the Repository

```bash
git clone <repository-url>
cd athar
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Project

```bash
npm run dev
```

Open the local URL shown in the terminal.
